# Data availability

## Suggested manuscript wording

The data underlying the main findings and the principal analysis code are publicly available at https://github.com/Zhaolin0912/visible-polarization-paper-data. The repository contains figure source data, aggregate simulation and empirical results, the core model implementation, and selected analysis scripts. Respondent-level ANES records and tweet-level text or identifiers are not redistributed; these source datasets can be obtained from their original providers.

## Repository scope

| Folder | Content |
|---|---|
| `data/figure2_baseline` | Baseline visible-bias estimates and time series |
| `data/figure3_layer_accounting` | Six-layer distributions and sequential accounting |
| `data/figure4_mechanism_landscapes` | Participation and expression parameter landscapes |
| `data/figure5_algorithm_landscapes` | Algorithm-parameter landscape |
| `data/figure6_matched_intervention` | Matched-endpoint intervention results |
| `data/figure7_ablations` | Main ablation results |
| `data/figure8_network` | Network-structure comparison |
| `data/figure9_empirical` | ANES and Twitter aggregate empirical results |
| `data/validation` | Human-validation summary statistics |
| `code` | Core model and selected analysis code |

The layer decomposition is a sequential accounting framework and should not be interpreted as causal attribution.
